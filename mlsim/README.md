# GripSense ML Lab

A separate demo that trains a small neural network, live, to predict how much grip force each object
needs. It runs on its own port (8100) next to GripSense (8000) and does not change or feed the main app.

```powershell
powershell -ExecutionPolicy Bypass -File .\run-mlsim.ps1     # Windows
./run-mlsim.sh                                               # Linux / macOS
```

Then open http://localhost:8100 and press **Train**. Pure Python standard library: no packages, no internet.

## What is real and what is simulated

- **The training is real.** A one-hidden-layer MLP (`model.py`, Adam, written from scratch) learns from
  the rows; every curve on the page comes from the model as it trains.
- **The data is synthetic.** `data/grasp_trials.csv` holds 900 simulated calibrations, generated by
  `dataset.py` from the friction physics plus hidden effects (material-specific friction error, extra
  force for narrow objects, noise, slider steps). The page says so. Regenerate: `python mlsim/dataset.py`.
- With real calibrations (GripSense's saved records), the same code would learn from those instead.

## What the page shows

- learning curve (training vs held-out validation error) and predicted vs actual for unseen trials;
- the learned minimum force for each GripSense object, with the plain formula, the simulator's hidden
  truth and the force GripSense calibrated in the sample data (that includes the ×1.5 margin);
- each object's prediction epoch by epoch;
- what it discovered: per-material friction corrections and the narrow-object effect, against the truth;
- the dataset, a CSV download, and a form to ask the model about any object.

Typical result: about 0.5 N average error on unseen trials, against about 1.0 N for the formula alone.

Tests: `python -m pytest mlsim`
